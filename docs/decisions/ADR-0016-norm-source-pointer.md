# ADR-0016 — General norms are consumed by pointer, not copy

## Status

Accepted

## Context

The template copies `docs/conventions.md` — the five discriminations, the budget table, the document discipline — into every generated repository, and this repository's conventions page says the copy is authoritative there. Five targets then carry five versions of one norm; a change lands in one and the others drift until someone notices. P1 says a fact has one authoritative home; the copy model gives a general norm as many homes as there are repositories.

The copy also has no freshness marker: a repository forged a year ago keeps presenting the forge-time text as current.

## Decision

This repository is the norm source for general norms: language, naming, citation, document discipline, and budgets. The template remains the shape a new repository copies; the norm source is the authority every repository that names it follows.

- A target defines the source once, on one line in its `AGENTS.md`: `Norm source: {{NORM_SOURCE}} = <path or URL>`. Every reference elsewhere writes `{{NORM_SOURCE}}/docs/conventions.md`; changing the source path edits that line and nothing else.
- A target's general-norm page is a base pointer plus deviations: `Base: {{NORM_SOURCE}}/docs/conventions.md. Read it first; this page records only deviations. Last read: <date>`. `Last read` is provenance, not a version lock; the source is read at its current state, and no gate fails on an old date.
- The executable half is not pointered. Formatter configuration, gate stages, and the budget numbers a checker enforces stay local, or derive from the source with a `generated by` header. The norm page states what a target's gate must contain; the portable checker (`B-0002`) verifies the definition and the stage.
- The rule that a generated repository's copy is authoritative is withdrawn. The source is authoritative for every repository that names it; a restated copy is a second home.

## Options considered

- **Keep the copy and add a sync command.** Rejected: a sync needs a schedule, a diff review per target, and someone to run it; the five-repository rollout already shows how much drift survives manual sync. A pointer has one state, always current.
- **Pin the source to a version or commit.** Rejected for now: it stabilises each target's meaning but adds a bump ritual and a second coordinate. `Last read` records provenance without pretending to be a lock.
- **Point at the spec pages (`0004-rules.md`) instead of the conventions page.** Rejected: the conventions page is the human-facing norm set and already links into the spec; a target page pointing at an internal spec page would still need the discriminations interpreted somewhere.
- **A shared package or submodule for the executable half.** Deferred, not rejected: `B-0002` and the overlay items decide the mechanism per language. A pointer cannot execute, and one package for TypeScript and Python would be a worse copy.

## Consequences

- A target page is no longer self-contained: without the source, a cold reader cannot use it. Accepted as the price of one home.
- A norm change reaches every target at once, and a target's deviations can silently go stale; `Last read` is the only marker, and nothing fails on it.
- The template's `docs/conventions.md` stops restating the discriminations and the budget table; its job is the pointer shape.
- `B-0002` gains the definition-resolution check: exactly one definition, every token resolvable, no absolute source path outside the definition.
- `docs/committing.md` remains an exception until `B-0013` moves its base here.
