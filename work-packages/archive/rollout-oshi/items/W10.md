# W10 — Give each work item its own file and the ledger a board

**Depends on**: none

`todo.md` reached 31,944 non-whitespace characters, and 77% of it was closed work: 18 closed items were 24,557, the five open ones 4,989, the dashboard 2,398. A conversation on one open item read all of it. The maintainer chose the full split after the three shapes were measured — collapsing closed items in place, moving only the closed ones, or one file per item; ADR-0029 records the decision, the rejected alternatives and the cost.

Each work item becomes `items/<ID>.md` carrying its dependencies, description, done-when criteria and evidence. `board.md` carries the current state and the index, grouped under the plan's phases, and is the only place a status lives. The four ledger artifacts stay four: spec, plan, board, summary. `items/` is reserved, not evidence, and archives with the package. The three archived packages keep their block shape; this package is the first application.

**Done when**:

- the norm, glossary, template, both work-package READMEs and the skill state the new shape
- the checker reserves `items/`, requires `board.md` in an open package, lets an archived package keep `todo.md`, and checks index/file parity plus the item heading
- this package is migrated: one file per item and a board, with `plan.md` pointing at the item files
- the archived packages pass without a rewrite

**Evidence**:

- ADR-0029.
- `356e344` — norm, glossary, ADR; `1fe4b9a` — template, READMEs, skill; this commit — checker, tests, migration.
