# W12 — Point `template/core/docs/structure.md` at the norm instead of copying it

**Depends on**: W08 (ADR-0032)

ADR-0032 (2026-11-20) scopes the base pointer to a target's general-norm page and requires every other role page to link the norm page and section it relies on. `template/core/docs/structure.md` copies four norm facts — the three levels (`docs/norm/flow.md`, "Three levels"), the directory-index rule (`docs/norm/roles.md`, "Directory index"), the placement router (the role table on the same page), and the artifact tiers (`docs/norm/overlays.md`, C5) — so a repository forged from the template starts with a finding.

Convert this page: keep the template's own layout (the single-package default, `src/` and `tests/` at the root, the docs tree) and replace each copied section with the norm link it relies on.

`core/docs/README.md`, `effort/docs/adapters.md` and `effort/docs/suite-tracks.md` carry the same defect and take their own IDs after this page lands.

The review accepted the conversion with one amendment (2026-11-20): the artifact-tier table stays. The Structure role admits "artifact tiers", and ADR-0021 assigned the package-evidence row to this page, so only the section's closing header sentence was a copy and `Regenerable` left the acceptance grep. The same commit corrected the day-one checklist in `docs/workflow.md`, which described the page's old shape and counted three tiers where the page carries four.

**Done when**:

- `rg -n 'A repository has three levels|Is it normative for this repository' template/core/docs/structure.md` returns nothing
