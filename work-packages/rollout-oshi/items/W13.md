# W13 — Let the item description take the form its content needs

**Depends on**: none

The package's items grew as single blocks because the norm said prose and the template asked for one line: 26 items, the longest `W08` 2,914 characters, and an enumeration carried as a semicolon chain inside one sentence (`W07a` held seven commits in one). The maintainer asked for the form to follow the content, diagrams included, without padding.

ADR-0033 (2026-11-20) sets the form: prose, a list, a table, or a small fenced diagram, one screen, carrying what the item is and must hold; the done-when criteria stay bullets, and a description needing a heading per concern is more than one item. `docs/norm/flow.md` "Work items" states it, both `work-packages/README.md` copies drop "prose description", and the template's placeholder names the four forms.

**Done when**:

- the norm states the form instead of prescribing prose
- the template placeholder and both README copies match it
- ADR-0033 is accepted and indexed, and ADR-0009 and ADR-0029 record the partial supersede
- the items in this package are reflowed into the form each needs
- the gate is green

**Evidence**: standard `92633c7` (ADR-0033, the norm clause, the template placeholder, both README copies), `01f1773` (fourteen items reflowed). Gate PASS 148 markdown files, 87 tests; one soft `roles.md` warning, unchanged.
