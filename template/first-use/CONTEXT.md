# CONTEXT — vocabulary

Terms this repository uses with a fixed meaning. Add a row only when a term is used by two or more members, or when a synonym would cause a real mistake.

| Term         | Meaning                                  | Avoid                          |
| ------------ | ---------------------------------------- | ------------------------------ |
| example-term | One sentence a new maintainer can act on | the synonym that would mislead |

Rules:

- A term used by one member lives in that member's `CONTEXT.md`.
- `CONTEXT-MAP.md` lists locations and stores no definitions.
- When a definition changes, change it here and fix every pointer; do not add a second definition.
