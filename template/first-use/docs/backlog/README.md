# Backlog

Deferred items only. An item binds nothing; it records a decision that has not been made, with the evidence that would settle it.

## Rules

- Each item is its own file: `B-<nnnn>-<slug>.md`.
- Every item states `Revisit when`: the event that makes it actionable — a condition outside it, or a freed slot in the plan. A date is not a trigger.
- `Status` lives in the index, not the item file. The four states and their boundaries are defined in `{{NORM_SOURCE}}/docs/norm/roles.md` (Backlog index).
- Closing: write a one-line outcome under `## Outcome`, set the row to `closed`, keep the file and the row.
