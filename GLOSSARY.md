# GLOSSARY — vocabulary

Terms this repository uses with a fixed meaning. When writing a spec page, a template, or a commit message, use these words and avoid the synonyms listed as avoided.

| Term                            | Meaning                                                                                                                                  | Avoid                                     |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------- |
| **role**                        | One kind of document with one home, one admission rule, one exit rule, and one authority range.                                          | "doc type", "category"                    |
| **home**                        | The single path where a role lives.                                                                                                      | "location", "place"                       |
| **layer**                       | One of four strata: `core`, `overlay`, `adapter`, `optional`.                                                                            | "level" (reserved for root/member/module) |
| **level**                       | The ownership tier: root, member, module.                                                                                                | "layer"                                   |
| **overlay**                     | The per-language part of the skeleton: toolchain, gate, code layout, writing rules.                                                      | "plugin", "extension"                     |
| **adapter**                     | The registry and compatibility whitelist for third-party skill suites that hard-code their output paths. Not a physical directory layer. | "integration layer"                       |
| **track**                       | The workflow suite an effort started on, recorded as a field in `tasks/<slug>/spec.md`.                                                  | "pipeline", "flow"                        |
| **work package**                | One effort's four artifacts under `tasks/<slug>/`: spec, plan, todo, summary.                                                            | "task", "ticket"                          |
| **closeout**                    | The act of finishing a work package: write summary, relocate artifacts, extract decisions and knowledge.                                 | "wrap-up"                                 |
| **tombstone**                   | A ≤3-line forwarding stub kept only because a frozen record cites the old path.                                                          | "redirect", "alias"                       |
| **volume budget**               | The size limit of a document in non-whitespace characters.                                                                               | "length", "size"                          |
| **entry budget**                | The count limit of an index or table in rows.                                                                                            | "line limit"                              |
| **single-package degeneration** | The form a repository takes when it has one package: `apps/` and `packages/` disappear; `src/` and `tests/` sit at the root.             | "simplified mode"                         |
| **spec (work package)**         | `tasks/<slug>/spec.md`: what this one effort will do.                                                                                    | —                                         |
| **spec (contract)**             | `docs/contracts/<topic>.md`: what must stay true across efforts.                                                                         | —                                         |
| **generated artifact**          | A file produced by a command, marked `generated by <command> — do not edit`.                                                             | "build output"                            |
| **legacy path**                 | An old location kept temporarily during migration and registered in `docs/adapters.md`.                                                  | "old dir"                                 |
